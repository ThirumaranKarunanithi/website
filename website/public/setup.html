Required for AI

Install Ollama

Ollama runs AI language models locally on your PC. The app uses it to understand your plain-English questions and generate SQL — your data never leaves your machine.

ℹ
Ollama requires 8 GB RAM minimum. A dedicated GPU (NVIDIA with CUDA) gives faster responses but is not required — it also runs on CPU.
  1. Go to ollama.ai/download and download the Windows installer.
    Look for "Download for Windows (Preview)" — it's a straightforward .exe installer.
  2. Run the installer. Ollama installs as a background service and starts automatically.
    You'll see the Ollama icon in the system tray when it's running.
  3. Open Command Prompt or PowerShell and pull the AI model: 
    ollama pull llama3
# Downloads ~4.7 GB — may take several minutes on first run
  4. Verify the model downloaded successfully: 
    ollama list
# Should show something like:
# NAME            ID            SIZE    MODIFIED
# llama3:latest   365c0bd3c000  4.7 GB  2 minutes ago
  5. Keep Ollama running in the background. The app connects to it at http://localhost:11434.
    On Windows, Ollama starts automatically on login. To start it manually: ollama serve
✅
Test Ollama is working: open your browser and visit http://localhost:11434 — you should see "Ollama is running".

Install

Install Magizhchi DB Communicator

  1. Download the latest installer below:
    ⬇ MagizhchiDBCommunicator-Setup-0.2.2.exe
  2. Run the installer. No administrator rights needed — it installs into your user profile (%LocalAppData%\Programs).
  3. Follow the setup wizard. Optionally tick "Create a desktop shortcut" on the last page.
  4. Launch from the Start Menu (search "Magizhchi") or the desktop shortcut.
⚠
Windows SmartScreen may show a warning on first run because the app is not yet code-signed. Click More info → Run anyway to proceed.

Account

Sign in with Magizhchi Box

The app uses your Magizhchi Box account for authentication (the same account used across all Magizhchi apps). Sign-in is via a one-time code sent to your email — no password to remember.

  1. On the sign-in screen enter your email address and click Send OTP.
  2. Check your inbox for a 6-digit code and enter it in the app.
  3. Click Verify — you're signed in. The session persists across restarts.

Connect

Connect to your database

The app supports PostgreSQL, MySQL, SQL Server, Oracle, SQLite, MongoDB, Redis, and CouchDB.

  1. Pick your database type from the TYPE dropdown in the top bar.
  2. Fill in HOST, PORT, DATABASE, USERNAME, and PASSWORD.
  3. Click Connect. The status pill turns green and the left sidebar fills with your tables.
  4. Optionally save the connection for later: click 💾 Save, type a name, and press Enter.
    Saved connections appear in the SAVED dropdown. You can switch with a click or by typing "load saved connection <name>" in the chat.
ℹ
Railway / cloud databases: paste the full connection URL into the HOST field — the app will parse it automatically. Make sure your IP is whitelisted in the cloud provider's firewall.

Help

Troubleshooting

ProblemSolution
Ollama returned 500 / CUDA error GPU ran out of memory. Ollama will retry on CPU automatically. If it keeps failing, restart Ollama: open Task Manager → find "ollama" → End task → run ollama serve again.
Connection failed: invalid TimeZone "Asia/Calcutta" Fixed in v0.1.4+. Use the Relaunch button to update.
App shows "Disconnected" after PC sleep Click Connect again — idle cloud connections time out. Use local databases for always-on access.
Tables sidebar is empty after connect Click the ⟳ Refresh Schema button in the top bar.
SmartScreen warning on install Click More info → Run anyway. The app is safe; it's simply not yet code-signed.
AI answers are wrong or slow Make sure llama3 is pulled (ollama list). Larger models give better answers — try ollama pull llama3:70b if you have 32 GB+ RAM.
Update available — how to update Click the ↺ Relaunch button. If a newer version is found you'll be offered "Update & Relaunch".
